Fundzy

Scholarship information, minus the overwhelm.

Fundzy is an independent student information platform designed to make scholarship discovery easier for students across Uttar Pradesh and India.

It helps students explore scholarship programmes, understand eligibility requirements, prepare necessary documents and access official application portals — all in one place.

🌐 Website: https://fundzy.co.in/

Features

Scholarship Discovery: Search scholarship programmes and filter by study level, state, coverage, category and listed application status.

Eligibility Guidance: Understand scholarship eligibility requirements and important conditions.

Document Preparation: Explore document checklists to prepare before applying.

Official Application Links: Access the original scholarship provider's website to complete applications.

Application Tracker: Track personal preparation and application progress in the current browser.

Data Backup: Export and import tracker information in JSON format.

Fundzy AI Assistant: Get conversational assistance with scholarship discovery, eligibility questions, course-related queries and document preparation.

Multilingual Assistance: Ask questions in English, Hindi or Hinglish.

Responsive Design: Access Fundzy on mobile phones, tablets and desktops.

Theme Options: Switch between light and dark modes.

Mobile Navigation: Simple navigation with accessible menu controls.

Fundzy AI Assistant

Fundzy includes an AI-powered assistant designed to make scholarship discovery more convenient.

Students can use it to:

Explore scholarship opportunities based on their course.

Understand eligibility requirements.

Prepare scholarship documents.

Ask questions about different education levels.

Data Accuracy

The scholarship catalogue is a manually maintained collection of information, not a live government database or synchronised application feed.

The catalogue was reviewed against official listings on 18 October 2026.

Some entries may be:

Currently accepting applications.

Available only for renewals.

Subject to additional eligibility conditions.

Awaiting confirmation of application dates.

Included as discovery guides rather than confirmed active opportunities.

Scholarship availability, deadlines, award amounts and eligibility conditions can change.

Always verify the latest information through the official provider before applying.

Privacy

Fundzy is designed to provide scholarship information without requiring users to create an account.

Personal tracker information is stored in the current browser.

Tracker data is not automatically synchronised across devices.

Users can export and import their tracker information.

The platform does not require users to upload identity or financial documents.

Privacy reminder: Never share Aadhaar numbers, bank account details, passwords, OTPs or other sensitive personal information through the website or its assistant.

Disclaimer
