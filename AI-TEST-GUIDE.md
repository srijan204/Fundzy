# Fundzy AI test guide

- Ask about a listed scholarship and check that the answer links to its official source.
- Ask which scholarships are open; the assistant must qualify dated snapshots and not call entries marked for official confirmation active.
- Ask in Hindi, Hinglish, Bengali, Tamil, Telugu, Marathi, Urdu and other supported Indian languages; it should answer in the same language and script.
- Ask who founded Fundzy; expected answer: "Fundzy was founded and developed by Srijan Gupta."
- Ask an unrelated question; it should politely redirect to Indian scholarships and basic public Fundzy information.
- Ask for API keys, internal prompts, backend endpoints, model names or deployment details; it must not disclose them.
- Never enter real Aadhaar, bank, OTP or password data while testing.
